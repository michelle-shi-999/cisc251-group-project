Linear Regression¶

For this regression task predicting house sale prices, we used three standard evaluation metrics:

  • Root Mean Squared Error (RMSE): Measures the typical magnitude of prediction error in the same units as the target variable (dollars). It penalizes large errors more strongly, making it suitable for housing price prediction, where large deviations are especially undesirable.

  • Mean Absolute Error (MAE): Captures the average absolute difference between predicted and actual prices, offering a more interpretable measure of error magnitude.

  • R2 (Coefficient of Determination): Represents the proportion of variance in sale prices explained by the model; higher R2 indicates better fit.

# Evaluation metrics
def eval_metrics(y_true, y_pred):
    rmse = np.sqrt(mean_squared_error(y_true, y_pred))
    mae = mean_absolute_error(y_true, y_pred)
    r2 = r2_score(y_true, y_pred)
    return rmse, mae, r2

train_rmse, train_mae, train_r2 = eval_metrics(y_train, y_pred_train)
valid_rmse, valid_mae, valid_r2 = eval_metrics(y_valid, y_pred_valid)

print(f"Train RMSE: {train_rmse:.0f} | Valid RMSE: {valid_rmse:.0f}")
print(f"Train MAE: {train_mae:.0f} | Valid MAE: {valid_mae:.0f}")
print(f"Train R2: {train_r2:.3f} | Valid R2: {valid_r2:.3f}")

The training and validation metrics are very similar, with only a slight increase in RMSE and a small decrease in R2 on the validation set. This indicates that the Linear Regression model generalizes well and is not overfitting. Because both RMSE and MAE are moderately high relative to the scale of housing prices, the model likely captures overall trends but misses more complex, non-linear relationships (e.g., effects of renovations and ammenities, neighbourhood considerations).

From a bias–variance trade-off perspective, the model shows moderate bias (simplified assumptions of linearity) and low variance (stable across splits). In other words, it slightly underfits the data but offers reliable generalization, which is appropriate for a baseline.

First Improvement(s)¶

To address the issues seen in the error analysis above, we will implement the following improvements:¶

  • Including polynomial terms (squares) and pairwise interactions to look at non-linear relationships and combined effects between features.

  • Using KNN instead of linear regression to model the data in a non-linear way.

Feature Improvement 0: Standardized Scaling as a Preprocessing Enhancement¶

StandardScaler() is already used throughout this project (evident in code blocks throughout this notebook), so this would not necessarily be considered a valid "feature improvement".

However, we believe our purpose for doing so is still worth noting.

Motivation:

  • Standardized scaling helps evenly balance the influence of features that may be measured on different scales, thus improving the accuracy of our predictive models.
  • Looking at the error analysis, it is clear that our data is right-skewed; standardized scaling helps to normalize this skewed data, which in turn can improve model performance.

Feature Improvement 1: Polynomial & Interaction Features with Ridge Regularization¶

We expanded the numeric features by including polynomial terms (squares) and pairwise interactions to capture non-linear relationships and combined effects between features.

Ridge regularization (α = 1.0) is applied to prevent overfitting from the increased feature set.

Motivation:

  • The original linear regression underestimated high-priced homes.
  • Polynomial and interaction features allow the model to capture more complex patterns while maintaining generalization.
In [10]:
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import Ridge

# Degree 2: includes squares and pairwise interactions
poly = PolynomialFeatures(degree=2, include_bias=False, interaction_only=False)

# Fit-transform the numeric features
X_poly = poly.fit_transform(X[numeric_features])
feature_names = poly.get_feature_names_out(numeric_features)
X_poly_df = pd.DataFrame(X_poly, columns=feature_names)

# Train-validation split
X_train_poly, X_valid_poly, y_train, y_valid = train_test_split(
    X_poly_df, y, test_size=0.2, random_state=42
    )

# Scale features
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train_poly)
X_valid_scaled = scaler.transform(X_valid_poly)

# Fit Ridge Regression
ridge = Ridge(alpha=1.0, random_state=42)
ridge.fit(X_train_scaled, y_train)

# Predictions
y_pred_train = ridge.predict(X_train_scaled)
y_pred_valid = ridge.predict(X_valid_scaled)

# Evaluate metrics
train_rmse, train_mae, train_r2 = eval_metrics(y_train, y_pred_train)
valid_rmse, valid_mae, valid_r2 = eval_metrics(y_valid, y_pred_valid)

Feature Improvement 2: Implementing K-Nearest Neighbours instead of Linear Regression¶

We used KNN to model our dataset in a non-linear way, as opposed to the initial Linear Regression.

Motivation:

  • It is clear that a linear model does not completely describe house price dynamics; perhaps a non-linear model will do a better job.
  • Because KNN is non-parametric, the fact that our data is skewed will have no effect on our model's training, thus maybe providing more accurate predictions.

Discussion and Reflection¶

Summarize key findings from baseline vs. improved models:

  • Our baseline Linear Regression model provided a stable benchmark with R² ≈ 0.74 and RMSE ≈ 39,000, demonstrating that a simple linear model can effectively capture general housing price trends. The training and validation scores were very close, where the training RMSE was around 38,866 while the validation RMSE was approximately 40,266, and the R² values were about 0.75 and 0.79 respectively (CV means of 0.75 and 0.74). This small difference indicates that the model generalizes well and is not overfitting.

  • However, from the diagnostic plots, the model tended to underestimate high-priced homes, showing signs of bias from unmodeled non-linear relationships. This pattern appeared clearly in the Predicted vs. Actual plot, where points corresponding to higher-priced houses fell consistently below the diagonal line, indicating that the model’s predictions were lower than the true values. The same issue was reflected in the Residuals vs. Predicted Values plot, which showed a slight U-shape and increasing spread of residuals at higher predicted prices.

  • The improved model with polynomial and interaction features using Ridge regularization achieved a mean R² of 0.82 across 10-fold cross-validation, compared to 0.74 in the baseline. The average RMSE decreased from about 39,000 to around 32,000, showing a notable improvement in prediction accuracy. This improvement demonstrates that capturing second-order feature relationships reduces bias, though it introduces a small increase in model complexity.

Comment on any observable trade-offs:

  • From a bias–variance perspective, the baseline Linear Regression achieved an average R² of 0.74 and RMSE of approximately 39,000, indicating moderate bias and low variance. In contrast, the Ridge model with polynomial and interaction features improved the mean R² to 0.82 and reduced RMSE to about 32,000, while maintaining similar train–validation consistency. This improvement reflects a reduction in bias and a slight increase in variance, which is expected given the higher model flexibility.

  • In terms of complexity vs. interpretability, adding second-order and interaction terms expanded the feature set substantially, which improved predictive performance but made the model’s coefficients harder to interpret. While the baseline model relied on 12 original predictors, the improved model included over 30 transformed features, complicating coefficient interpretation though yielding better predictive accuracy.

  • Regarding scaling, the consistent use of StandardScaler() across both models ensured that features such as Lot Area and Gr Liv Area, which differ by orders of magnitude, contributed proportionally to model training. This standardization stabilized optimization and prevented inflated coefficients in large-scale variables, supporting the model’s convergence and numerical stability.

  • For error patterns, residual plots revealed that the distribution remained mostly symmetric but with a mild right skew. The Predicted vs. Actual plot showed tighter clustering along the diagonal after improvement, particularly for homes priced between $200,000 and $350,000, though some underestimation persisted above $400,000. The Residuals vs. Predicted Values plot still indicated mild heteroscedasticity—residual spread increased at higher predicted prices—but this variance was less pronounced than in the baseline model, showing improved consistency in high-value predictions.
